# 🤖 AI WooCommerce Chatbot

An AI-powered chatbot for WordPress WooCommerce stores — similar to WoowBot Pro.

## Features
- Product search & recommendations from your WooCommerce catalog
- Order tracking by order ID/email
- FAQ handling & store policy information
- Add to cart directly from chat
- Exit intent & cart abandonment recovery
- Lead capture & newsletter subscription
- Admin settings dashboard
- Chat analytics
